# IN

`IN` is used to check whether a value matches any value inside a list.

## Example

```sql
SELECT name, category, price
FROM products
WHERE category IN ('Electronics', 'Furniture');
```

## How it works

The condition:

```sql
category IN ('Electronics', 'Furniture')
```

returns products whose category is either `Electronics` or `Furniture`.

The same condition could be written using `OR`:

```sql
WHERE category = 'Electronics'
   OR category = 'Furniture';
```

Using `IN` makes the query shorter and easier to read when comparing the same column against multiple values.

## NOT IN

`NOT IN` performs the opposite operation:

```sql
WHERE category NOT IN ('Electronics', 'Furniture');
```

It returns rows whose value does not match any value in the list.
